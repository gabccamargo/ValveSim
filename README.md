ValveSim is a free plugin designed to simplify virtual transcatheter valve implantation planning using cardiac CT images.

The plugin enables users to reconstruct valve annular geometry from anatomical landmarks, interactively simulate prosthesis implantation, and visualize changes in device dimensions, positioning, and orientation in real time.

Key Features

Annular Reconstruction: Define the target annulus using manually placed anatomical landmarks and obtain geometric measurements.

Interactive Valve Simulation: Customize prosthesis diameter, height, implantation depth, position, and orientation.

Real-Time CT Visualization: Display the simulated prosthesis directly on CT images and multiplanar reconstructions (MPR).

C-Arm Planning: Explore annular coplanar projections and CT-based virtual fluoroscopy.

DICOM Export: Generate simulated CT series with the virtual prosthesis embedded in the image data, compatible with other DICOM viewers.

Compatibility

Developed for Horos, with compatibility tested on OsiriX Lite and IsiX, running on Intel and Apple Silicon Macs.
